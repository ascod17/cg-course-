# Компьютерлік графика (C++ / OpenGL 3.3)

| Апта | Тақырып | Тег | Көшірме файл |
|---|---|---|---|
| 1 | Терезе, ауысатын фон (көк→фиолет→голубой), Пробел = ақ | `week01` | `weeks/week01_main.cpp` |
| 2 | VBO + VAO, диагональмен қиылған үшбұрыштар торы | `week02` | `weeks/week02_main.cpp` |
| 3 | Үшбұрыштардан пирамида, n қатар қолмен енгізіледі | `week03` | `weeks/week03_main.cpp` |

Іске қосу (Ubuntu / WSL):

```bash
cmake -B build
cmake --build build
./build/bin/cg
```

Бағдарлама n-ді сұрайды (мысалы 5). Терезеде: Пробел (басып тұр) — ақ фон,
↑/↓ — қатар санын өзгерту, Esc — шығу.

Белгілі аптаға оралу: `git checkout week02` (қайту: `git checkout main`).
